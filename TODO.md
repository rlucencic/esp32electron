# esp32electron: what's next

In order. A finished item goes into CLAUDE.md (what it is, how it was
checked) and leaves this list.

1. **Tapes**: UEF images (gzip too) through the ULA's cassette interface
   (high tone, bytes, the interrupts), with the motor; *CAT, LOAD, CHAIN,
   *RUN; the archive.org TOSEC games (~/Development/electron-dl), a fast
   load. The Tape drive (setup screen, web page) and the `electron/`
   folder are there already, holding a tape's name only: make it play.
2. **The Plus 3** (the user, 2026-11-18: right after tapes): the WD1770 and its latch at $FCC0, the ADFS ROM in page
   4, 3.5" ADFS images (.adf/.adl): *CAT, LOAD, SAVE, *FORM80/*COMPACT,
   kept after remounting (esp32emu's plan: required).
3. **Original software**: the games and applications from the TOSEC set;
   ROM cartridges (the Plus 1); the SSD images through ACP's 1770 DFS.
4. **GitHub**: the repository public with screenshots and topics, when the
   user wants it.
